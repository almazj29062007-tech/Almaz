# Флаги · WebGL · 5 секунд

Запуск: `python3 server.py`, затем http://localhost:8765.

Откройте исходный PNG/JPG кнопкой «Открыть изображение». Нужен оригинал из задания с той же композицией 16:9. Изображение хранится локально; внешних запросов и библиотек на странице нет.

Кнопка «Экспорт MP4» запускает покадровый рендер через Chromium и ffmpeg. Результат: flags-1080p.mp4, H.264, yuv420p, 1920×1080, 30 FPS, ровно 150 кадров / 5 секунд, без звука. Последний кадр имеет время 149/30; дублирующего кадра в конце нет.

Требования для экспорта: Python 3, Node.js, ffmpeg, Chromium, playwright-core (`npm install playwright-core`). Путь к Chromium можно задать переменной CHROMIUM_PATH. HTML-просмотр работает в современном браузере с WebGL.

Деформация: несколько периодических волн в WebGL-шейдере, отдельные маски левого и правого флагов по координатам исходного референса. Силуэты закреплены, внутренние складки смещаются. Это деформация фотографии, а не физическая 3D-симуляция отдельных полотнищ. Исходные свет и тени не пересчитываются. Для свободного движения силуэтов нужны отдельные слои флагов и фон без флагов.

Исходник из чата недоступен как файл в рабочей среде. До его получения визуальная проверка соответствия оригиналу и окончательный MP4 невозможны. Тестовое изображение не является частью проекта.
